# Voice

Player characters speak their chat aloud as a babble generated on each client. Players set it on the character
creator's Voice tab: voice type (the species' `speechVoice` by default), pitch, speed, pitch variance, intonation, size
and melody, or Speak with to keep the message sound. Options, Audio, Play character voices turns voices off for one
listener. Entry points: `SpeechVoice` (saved in the profile), the server `SpeechVoiceSystem` (sends each listener the
line), the client `SpeechVoiceSystem` (plays it) and `SpeechVoiceSynth` (renders it). CVar: `wf.voice.enabled`.
